Section 1

Abstract

This project presents an AI-Based Cyber Fraud Detection System designed for digital banking environments. The system provides a complete, browser-based security dashboard that monitors synthetic banking transactions, assigns explainable fraud risk scores, and enables security analysts to investigate and resolve alerts.

The fraud detection engine implements eight rule-based detection patterns inspired by real-world banking fraud scenarios, including high-value transaction detection, rapid successive transactions, unusual transaction locations, repeated identical amounts, and behavioral deviation from customer norms. Each detection produces a transparent, human-readable explanation — making the system auditable and accountable.

The application was built as a single-file web prototype using HTML5, CSS3, and vanilla JavaScript with no external dependencies. It runs entirely in any modern browser, uses browser localStorage for data persistence, and is fully self-contained. Precision of 92.3%, Recall of 80.0%, and an F1 Score of 85.7% were achieved on the labeled synthetic dataset. All 54 automated tests pass.

The primary objectives of this project are:

  • 4
    Display suspicious activity on a professional security dashboard with live charts and KPI metrics.
  • 5

  • 8

Section 4

Fraud Detection Methodology

The detection engine uses a rule-based explainable scoring approach. Every transaction is analyzed against the customer's historical transactions. Each triggered rule adds a weighted score. The final score is capped at 100 and classified into three risk levels.

Risk Classification Thresholds

Risk LevelScore RangeAction Required
Low0 – 29No alert raised, transaction passes normally
Medium30 – 59Alert raised, analyst review recommended
High60 – 100High-priority alert, immediate investigation

Detection Rules

#Rule NameWeightTrigger Condition
1High-Value Transaction25Amount ≥ ₹1,00,000
2Very High-Value Transaction35Amount ≥ ₹5,00,000
3Rapid Successive Transactions30≥ 3 transactions from same customer within 5 minutes
4Unusual Transaction Hour15Transaction between midnight and 5 AM
5Repeated Identical Amount20Same exact amount ≥ 2 times within 1 hour
6Large Deviation from Average30Amount > 3× customer's historical average
7Unusual Transaction Location20City differs from customer's recent transaction history
8Successive High-Value Transactions25≥ 3 consecutive transactions each ≥ ₹50,000

All thresholds and weights are configurable via FraudEngine.CONFIG in the source code. Final score = min(sum of triggered weights, 100).

Section 5

Application Modules

5.1 Dashboard

The dashboard provides a real-time overview of the fraud monitoring state. It displays four KPI cards (total transactions, suspicious count, high-risk alert count, and detection rate on labeled data), a 14-day transaction activity line chart, a risk-level distribution donut chart, and a recent suspicious alerts table.

5.2 Transaction Monitoring

A fully paginated and sortable table showing all transactions. Analysts can search by transaction ID, customer name, location, or amount. Filters are available for risk level, payment channel, transaction type, and investigation status. Any transaction row can be clicked to open the investigation panel.

5.3 Alert Investigation

Displays all Medium and High-risk transactions sorted by risk score. Each alert can be opened in a slide-in detail panel showing complete transaction information, the risk score bar, and a list of every fraud rule that triggered. Analysts can update the status (New → Under Investigation → Reviewed → Confirmed Fraud / Legitimate) and record investigation notes. All changes persist via localStorage.

5.4 Transaction Simulator

A live demonstration tool with five transaction generation modes: Normal Transaction, High-Value Transfer (₹2L–₹8L), Rapid Transactions (5 in 5 minutes), Unusual Location, and Batch of 10 random transactions. Each generated transaction is immediately analyzed by the fraud engine and the result is displayed in a real-time console log with color-coded risk levels.

5.5 Reports & CSV Export

Provides a complete analytical summary including total and categorized transaction counts, detection performance metrics (Precision, Recall, F1 Score, Confusion Matrix) computed against ground-truth labeled data, a risk score histogram, and a rule frequency bar chart showing which rules fire most often. A downloadable CSV report of all transactions with scores is available.

Section 8

Security Considerations

  • ✅No real banking data — all transactions are synthetic and fictional. No real account numbers, PINs, CVVs, OTPs, or customer PII are stored or processed.
  • ✅No external network connections — the application makes zero API calls. No data leaves the browser.
  • ✅XSS prevention — all user-facing data is passed through an esc() function that converts < > & " ' to HTML entities before rendering.
  • ✅No hardcoded secrets — no API keys, tokens, passwords, or credentials exist anywhere in the codebase.
  • ✅Input validation — the fraud engine handles non-numeric amounts and empty history arrays without throwing errors.
  • ✅Safe error handling — all localStorage operations are wrapped in try/catch blocks to handle quota exceeded and parsing errors gracefully.
  • ✅No production API integration — the application does not connect to any Bank of Baroda system, payment gateway, or banking infrastructure.
  • ✅DEMO labels — every page displays a clear "⚠ DEMO — Synthetic Data Only" disclaimer banner.

Section 10

Conclusion

This project successfully demonstrates a complete, working AI-based cyber fraud detection system for digital banking. The system detects eight categories of suspicious transaction patterns, assigns explainable risk scores, provides a full analyst investigation workflow, and generates measurable detection performance metrics.


On the labeled synthetic dataset, the rule-based engine achieved Precision of 92.3%, Recall of 80.0%, and an F1 Score of 85.7% — indicating strong performance for a rule-based system with no machine learning training required. All 54 automated tests pass with a 100% pass rate.


The system demonstrates the core concepts used in real enterprise banking fraud monitoring platforms, including rule-based anomaly detection, risk scoring, alert management, and analytical reporting — implemented in a transparent, explainable, and academically rigorous manner.
