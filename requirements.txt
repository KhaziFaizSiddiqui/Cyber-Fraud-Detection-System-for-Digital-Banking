# ------------------------------------------------------------
# HOW TO RUN
# ------------------------------------------------------------

Step 1 : Open File Explorer
Step 2 : Navigate to the banking-fraud-detection folder
Step 3 : Double-click index.html
Step 4 : Application opens in default browser — no setup needed

To run tests:
Step 1 : Double-click test-results.html  (static results)
         OR
Step 1 : Double-click run-tests.html     (automated runner)

Option B — Node.js (if installed):
    npx serve .
    Then open: http://localhost:3000/index.html

Option C — VS Code Live Server extension:
